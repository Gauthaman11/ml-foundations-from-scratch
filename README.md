From-scratch implementations of fundamental machine learning, computer vision, and natural language processing algorithms in pure Python and NumPy.

## Project Structure
- `src/`: Modular algorithm implementations (no high-level ML libraries).
- `tests/`: Automated unit tests using `pytest`.
